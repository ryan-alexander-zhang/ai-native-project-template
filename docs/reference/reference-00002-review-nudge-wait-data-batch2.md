## 4. Relevance

- 两轮把第一批的三轮样本扩到五轮，但强度未变：仍是口头收集的小样本，引用时
  须与 `reference-00001` 带同样的限定。

  "跨周末"。等待长短与"人在不在电脑前"直接对应，正对着 `idea-00002` 那条
  "本机通知中心够不够到'不在电脑前'"的 Open Question——41 小时那轮是本机通知
  中心够不到的形态，9 小时那轮则是人在电脑前且并未卡住。
- 反例是第一次出现"提醒本身有代价"的证据，指向提醒节奏与静音时段，归
  `idea-00002` 的 Open Questions 裁定。
- 反例中的"提醒"指什么，材料未交代——本 idea 的评审提醒尚不存在，故不能推定
  它说的是同一个东西；按输入原样留证。
